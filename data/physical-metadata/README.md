# Physical metadata

Campos deseados por concurso:

- contest
- draw_datetime
- sphere_set_id / estuche
- machine_id
- ball_type
- weight_01 ... weight_28
- min_weight / max_weight / range_weight
- set_changed
- incidents
- rfid identifiers if public
- metadata_available_before_close (boolean)

Una señal física puede ser `research_edge` sin ser `actionable_edge`.
