# ORIGEN roadmap

## v0.1 — Frames
Alternative lenses, deterministic frame IDs, registry, three critique roles.

## v0.2 — Research governance
Preregistration schema, event ledger, basic null generators.

## v0.3 — Statistical evaluation and audit
Chronological and rolling-origin splitters, paired prequential scoring, exact sign test, Holm correction, adversarial-null benchmarking, diversity diagnostics, SHA-256 manifests, evidence-gated classifications.

## v0.4 — Planned
A reproducible experiment runner with immutable run manifests; standardized draw/event adapters with explicit provenance; richer calibration and proper-scoring diagnostics; sequentially valid e-process only where its assumptions are formally specified; independent reviewer reports. No automatic data acquisition or model promotion.
