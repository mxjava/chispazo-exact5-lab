## Method

For each chronological window (all 6,923; last 1,600; last 800; last 400), calculate the mean per-target `log_lift_vs_uniform` for V322, V323 and the paired difference V322 minus V323.

Uncertainty sensitivity uses a circular moving-block bootstrap:
- 20,000 replications per series/window/block length.
- PCG64 generator, seed 20261120.
- Block lengths 7, 14 and 28 consecutive Classic targets.
- Each replicate samples circular block start indices with replacement, concatenates blocks, truncates to the original window length and calculates the mean.
- Reported intervals are percentile 95% intervals.

The bootstrap is a dependence-sensitivity diagnostic only. Circular blocks assume a degree of local stationarity; regime shifts and the post-hoc choice of windows limit interpretation. No p-value in this note is used as confirmatory evidence, no Holm family is claimed, and no anytime-valid e-value is computed.

## Reproduction outline

For a vector `x`, window length `n`, block length `L` and replication count `B=20000`:

```python
import math
import numpy as np

rng = np.random.default_rng(20261120)

def circular_mbb_means(x, L, B=20_000):
    x = np.asarray(x, dtype=float)
    n = len(x)
    blocks = math.ceil(n / L)
    starts = rng.integers(0, n, size=(B, blocks))
    offsets = np.arange(L)
    indices = (starts[:, :, None] + offsets[None, None, :]) % n
    samples = x[indices].reshape(B, -1)[:, :n]
    return samples.mean(axis=1)
```

Use the same ordered windows and series for exact reproduction of the single seeded run; calculate percentile quantiles at 0.025 and 0.975.
